Say it.
It's typed.

Hold a key, talk, let go. The text lands in whatever window you are in. Whisper runs on your own machine, and nothing leaves it unless you pick a cloud engine.

Download Every system, or build it yourself

Three moves, no window.

  1. 01
    SuperShiftD

    Hold the key

    Any combination, or one spare key like Right Alt or F13. A short tap keeps it recording until the next press.

  2. 02

    Talk

    In English or any of the 99 languages Whisper knows. Give it a short list and it picks the likeliest one each time.

  3. 03
    Sounds good, ship it.

    Let go

    The text is typed where your cursor is: the editor, the terminal, the chat. Or piped, if you run it from a script.

Yours by default. The cloud only when you ask.

A single binary, a settings page that runs offline, and plain text files you can read.

Runs on your machine

Your voice turns into text on your own computer, faster with a graphics card. No account, no internet.

Or streamed, if you want

Bring an ElevenLabs key and it transcribes while you talk, done about 0.3 s after you let go. No model to download at all.

Knows the words on screen

It reads the focused screen as you start, so names like useSettingsStore come out spelled right.

Cleans up after you

Takes out the ums, false starts and background noise, and fixes the punctuation.

Binds its own hotkey

Hold to talk on Linux and Windows. On niri and Hyprland it sets the shortcut for you; on a Mac, Raycast or skhd can start it.

Keys stay out of dotfiles

API keys live in their own file, readable only by you, away from the config you sync to GitHub.

A command first, an app second.

Pipe it, bind it, script it. When you would rather click, rookey setup opens a settings page for models, languages, keys and the hotkey, served from the binary itself.

Get rookey

Free and open source. The installer puts one binary on your PATH; rookey setup asks before it downloads a speech model.

Recommended

One line

curl -fsSL https://rookey.click/install | sh

Uses your NVIDIA card if you have one, the CPU otherwise. It asks before downloading a speech model.

Or grab the binary

x86_64, NVIDIA (CUDA)rookey-x86_64-linux-cuda.tar.gz x86_64, CPUrookey-x86_64-linux.tar.gz

Also wants wtype to type the text, grim for screen terms, and the input group for the hotkey.

Apple silicon

One line

curl -fsSL https://rookey.click/install | sh

macOS, Apple silicon (Metal)rookey-aarch64-macos.tar.gz

Windows 10 and 11

One line, in PowerShell

irm https://rookey.click/install.ps1 | iex

Uses your NVIDIA card if you have one, the CPU otherwise. It asks before downloading a speech model.

Or grab the binary

x86_64, NVIDIA (CUDA)rookey-x86_64-windows-cuda.zip x86_64, CPUrookey-x86_64-windows.zip

Unzip it anywhere on your PATH, then run rookey setup.

With cargo

git clone https://github.com/7KiLL/rookey cd rookey cargo install --path . # CPU cargo install --path . --features cuda # NVIDIA cargo install --path . --features metal # macOS

Needs Rust, cmake and a C++ compiler; whisper.cpp is built from source.

Then

rookey setup

Checks the mic, then downloads the model you pick, or takes an ElevenLabs key instead.
