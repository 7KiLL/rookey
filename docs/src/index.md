# rookey docs

Hold a key, talk, let go: the words are typed into whatever window you are in. One binary for Linux, macOS and Windows, with your own ElevenLabs key or Whisper on your machine. The [README](https://github.com/7KiLL/rookey#readme) says why; these pages say how.

- [Install](./install.md): the one-liners, what each system needs, builds, updates, uninstall
- [Commands](./commands.md): every `rookey` command, and the transcript history
- [Hotkeys](./hotkeys.md): hold to talk, desktop binds, how the text gets typed
- [Engines](./engines.md): ElevenLabs and the local models, languages, what leaves your machine
- [Screen terms](./screen-terms.md): names read off your screen so they come out spelled right
- [While you talk](./while-you-talk.md): the sounds, the pill, notifications
- [Settings](./settings.md): every setting, the config file and the keys file
- [Status for bars](./status.md): Waybar and Quickshell
- [Troubleshooting](./troubleshooting.md)
- [Compared](./compared.md): the alternatives, and what a month costs

The skill for coding agents, `rookey skills --install`, points here as well.
